# Personal Portfolio

A single-page portfolio layout with home, about, skills, projects, contact, navigation, and a downloadable CV.

## Run

Serve this folder as a static site or open `index.html` in a browser. No build or API key is required.

## Files

- `index.html` — portfolio sections and links.
- `style.css`, `script.js` — presentation and navigation behavior.
- `DSC_0001 copy.jpg`, `bk2.webp`, `resuma.pdf` — personal media and CV assets.

## Before publishing

Confirm you own and intend to publish the photo and CV; remove private information. Replace placeholder social/contact links and sample project text, check that the referenced background image exists, and verify the CV link on a case-sensitive host.
