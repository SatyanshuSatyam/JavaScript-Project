# Landing Page

A responsive personal-services landing page with navigation, profile/about content, and service cards.

## Run

Serve this folder as a static site or open `index.html` in a browser. No build or API key is required.

## Files

- `index.html` — page sections and navigation.
- `styles.css`, `script.js` — responsive styling and navigation behavior.
- `web-developer.jpg` — page background. `developer.png` is currently unused.

## Known limitations

Replace sample content and placeholder links. The current HTML references a portrait file that is not in this folder; correct the path or add an authorized image. Check the icon/font references before publishing.
