# Quote for the Day

A quote-of-the-day interface that requests content from the API Ninjas Quotes endpoint and offers a share action.

## Run

Serve this folder as a static site and open `index.html`. No build is required.

## Files

- `index.html` — interface and inline API/share code.
- `style.css` — quote-card styling.
- `image.png` — tweet button icon. `image copy.png` is currently unused.

## Known limitations

API Ninjas authentication is not configured, and the current request/response and error handling need correction. Do not place a private API key in committed browser code; use a backend proxy for public hosting.
