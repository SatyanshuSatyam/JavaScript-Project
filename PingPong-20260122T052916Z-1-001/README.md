# Ping Pong Game

A beginner-friendly 2D Ping Pong game implemented with HTML5 canvas and JavaScript. The player controls paddles using the keyboard, tracks a score, and restarts the match with a reset button.

## Features

- Canvas-based game board
- Keyboard controls for both paddles
- Ball movement and collision detection
- Score tracking
- Reset button to restart the game

## Run

Serve this folder through a static web server or open the `PingPong/index.html` file in a browser.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/PingPong/`.

## Files

- `PingPong/index.html` — game layout and canvas markup
- `PingPong/style.css` — visual styling
- `PingPong/script.js` — gameplay logic and rendering

## Notes

This project is designed as a small browser game exercise and does not include sound effects, multiplayer networking, or AI opponents.
