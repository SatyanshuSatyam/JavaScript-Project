# Ping Pong Game

A simple arcade-style Ping Pong game built using the HTML canvas API. The game includes paddle movement, ball physics, collision detection, and a visible score.

## Run

Open `index.html` directly in a browser or serve the folder with a static web server.

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/` from the project directory.

## Files

- `index.html` — game canvas and controls
- `style.css` — layout and game styling
- `script.js` — game loop, physics, scoring, and controls
