# PracticeJS Calculator

A basic button-driven arithmetic calculator exercise.

## Run

Serve this folder as a static site or open `index.html` in a browser. No build or API key is required.

## Files

- `index.html` — calculator controls.
- `style.css` — calculator layout.
- `calculator.js` — button handling and arithmetic evaluation.

## Known limitations

The implementation uses `eval()`. Replace it with a constrained arithmetic parser and validate decimal, operator, and error behavior before treating it as production code.
