# Calculator

A compact button-based arithmetic calculator.

## Run

Serve this folder as a static site or open `index.html` in a browser. No build or API key is required.

## Files

- `index.html` — calculator controls.
- `style.css` — calculator layout.
- `script.js` — button handling and arithmetic evaluation.

## Known limitations

The implementation uses `eval()`. Replace it with a constrained arithmetic parser and validate malformed expressions and division-by-zero behavior.
