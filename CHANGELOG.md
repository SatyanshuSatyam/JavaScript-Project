# Changelog

Notable changes to this project collection are recorded here.

## [0.1.0] - 2026-10-08

### Added

- Repository overview, setup, deployment, contribution, and security documentation.
- Historical metadata report and safe current-dated snapshot migration scripts.
- Per-project guides and a project gallery page.
- Root ignore rules and an MIT license.
- GitHub Actions checks and GitHub Pages deployment workflow.
- Local configuration templates for weather API keys.

### Changed

- Removed weather API keys from tracked application source.

### Known limitations

- Several demos contain known functionality, validation, accessibility, and security defects; see `QUALITY_REVIEW.md`.
- Existing app folders include nested Git metadata that must be resolved before committing this collection as a single repository.
